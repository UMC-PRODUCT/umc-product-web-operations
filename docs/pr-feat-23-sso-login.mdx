## 📸 작업 내용

> 작업한 내용을 두괄식으로 작성해주세요

- 공통 SSO 로그인(`auth-client`)을 붙이고, 백오피스는 로그인 후 **운영진만** 들어오도록 인가를 분리했습니다.
- origin → `local` / `dev` / `prod` stage로 API·인증 앱 URL을 고정하고, `.env`는 로컬 오버라이드만 남겼습니다.
- 비운영진은 앱 토큰만 정리한 뒤 로그인 안내를 띄우고, 로그인·로그아웃 이동은 `replace`로 히스토리를 남기지 않습니다.
- 패키지 분리 경계·연동 가이드 문서를 추가했고, 디자인 시스템을 **0.11.1**로 올려 `HeaderDesktop` / `HeaderMobile`에 맞췄습니다.

## 🎞️ 주요 코드 설명

> 설명이 필요한 코드 위주로 작성해주세요

### auth-client stage 표와 앱 origin 매핑

```TypeScript
// @umc-product/auth-client stages (공통 URL)
export const SSO_STAGES = {
  local: { apiBaseUrl: "", authAppUrl: "http://localhost:5174" },
  dev: {
    apiBaseUrl: "https://api-dev.university.neordinary.com",
    authAppUrl: "https://dev.auth.university.neordinary.com",
  },
  prod: {
    apiBaseUrl: "https://api.university.neordinary.com",
    authAppUrl: "https://auth.university.neordinary.com",
  },
} as const

// src/shared/auth/resolve-sso-env.ts (백오피스 전용)
const ADMIN_ORIGINS: Record<string, SsoStage> = {
  "http://localhost:5173": "local",
  "https://dev.admin.university.neordinary.com": "dev",
  "https://admin.university.neordinary.com": "prod",
}

export function resolveSsoEnv(origin: string, runtime: SsoRuntimeEnv = {}) {
  return resolveAuthConfig({
    clientIds: { local: "local", dev: "backoffice", prod: "backoffice" },
    local: runtime,
    origin,
    origins: ADMIN_ORIGINS,
  })
}
```

- API·Auth 주소는 패키지 `SSO_STAGES`에 두고, 앱은 **허용 origin + clientId**만 가집니다.
- 배포는 env 없이 호스트만으로 stage가 정해지고, localhost만 `VITE_AUTH_APP_URL` / `VITE_SSO_LOGIN_MODE`(기본 `auth-app`)를 씁니다.

### 인증 vs 인가 — 비운영진 가드

```TypeScript
// src/routes/_admin/route.tsx
if (!isOperator(session)) {
  context.queryClient.removeQueries({ queryKey: adminSessionQueryKey })
  markOperatorOnlyLoginNotice()
  // 다른 서비스 로그인까지 끊지 않도록 SSO 세션은 남기고 이 앱 토큰만 지운다.
  await client.logout()
  throw redirect({ replace: true, to: "/login" })
}
```

- SSO 성공 ≠ 백오피스 출입 허가입니다. `/me`로 운영진(`isAdmin` / `isSuperAdmin`)인지 앱에서 판단합니다.
- 비운영진은 `sessionStorage` 안내 플래그 후 `/login`으로 보내고, **글로벌 SSO 로그아웃은 하지 않습니다.**
- “다른 계정으로 로그인”은 안내 UI에서 SSO 로그아웃을 명시적으로 태웁니다.

### 로그인·로그아웃 히스토리

```TypeScript
// auth-client: startLogin / global logout
location.replace(target) // assign 대신 replace

// 보호 라우트 → 로그인
throw redirect({ replace: true, to: "/login", search: { redirect: location.href } })
```

- 로그아웃·재로그인 후 뒤로가기로 보호 화면에 다시 들어가지 않도록 `replace`로 통일했습니다.

## 💬 기타 더 이야기해볼 점

- Amplify에 `dev.admin` / `admin` 커스텀 도메인을 붙이면 stage env 없이도 동작합니다. Amplify 기본 호스트만 쓸 경우에는 `VITE_SSO_STAGE` 같은 fallback이 필요할 수 있습니다.
- 공통 SSO는 `@umc-product/auth-client` 패키지로 분리했고, 앱 전용 코드(`features/auth`, origin 표)는 패키지에 넣지 않습니다.
- DS 0.11.1 업그레이드로 헤더가 `Header` → `HeaderDesktop` / `HeaderMobile`로 바뀌었습니다. IDE가 예전 0.10 타입을 보면 export 없음으로 보일 수 있어 TS 서버 재시작이 필요할 수 있습니다.
